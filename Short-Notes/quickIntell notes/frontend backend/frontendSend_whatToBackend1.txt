  const authorizationHeader = req.headers["authorization"];

  if (typeof authorizationHeader !== "string") {
    return null;
  }

## **Session Token vs JWT Token Comparison**

| Feature | **Session Tokens (Your App)** | **JWT Tokens** |
|---------|-------------------------------|----------------|
| **Storage Location** | Server-side in database (PostgreSQL Session table) | Client-side only (localStorage/cookies) |
| **Validation** | Requires database lookup on every request | Self-contained, validated cryptographically |
| **State** | Stateful (server maintains session) | Stateless (no server storage) |
| **Revocation** | Easy - delete from database | Difficult - token valid until expiration |
| **Size** | Small session ID (~32 chars) | Larger (hundreds of bytes with claims) |
| **Scalability** | Requires session store access | More scalable (no DB lookups) |
| **Security** | More secure - can be immediately invalidated | Vulnerable if stolen before expiration |
| **Expiration** | Stored in database, can be refreshed | Fixed at creation time |
| **Bearer Token Format** | `Authorization: Bearer <sessionId>` | `Authorization: Bearer <jwt>` |
